## Root Families

1. Specialized BER gate: Create renderer has its own `VisualizationManager.supportsVisualization(level)` check outside M11's generic KBE renderers. M20.8 adds Sable-only fallback gates for Mixer, Crafter, Portable Interface, Fluid Valve, and Rotation Speed Controller.
2. Behaviour item/value-box distance culling: Filtering and Link renderers compare the player to hidden storage-space centers. M20.8 ports the exact upstream Sable `distanceSquaredWithSubLevels` bridge.
3. ValueBox plot translation: generic Create value boxes translate from raw block position relative to camera. M20.8 ports the exact upstream Sable ValueBox PoseStack projection.
4. Fixture state: Blaze Burner dynamic model is Create-owned and requires a non-`NONE` heat level so a `BlazeBurnerBlockEntity` exists; M20.8 fixes only the canary state.

## Processing Diagnosis

Mixer is not promoted to a production compatibility failure by this matrix. M20.8 fixture inspection must distinguish invalid recipe/input state from a real Sable lookup failure before any semantic production patch. Crushing Wheels are recorded separately as the explicit M20 deferred known runtime failure after runtime proved the Create controller exists and the remaining issue is isolated to the controller entity/collision/processing boundary.
